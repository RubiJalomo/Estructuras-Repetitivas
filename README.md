## Descripción de los códigos

### 1. Contador de Dígitos
Este programa solicita un número entero al usuario y utiliza una estructura repetitiva para contar la cantidad de dígitos que contiene.

### 2. FizzBuzz
Este programa utiliza una estructura repetitiva para recorrer una serie de números y mostrar "Fizz" para los múltiplos de 3, "Buzz" para los múltiplos de 5 y "FizzBuzz" para los múltiplos de ambos.

### 3. Número Invertido
Este programa solicita un número al usuario y utiliza una estructura repetitiva para invertir el orden de sus dígitos.

### 4. Suma de Pares e Impares
Este programa utiliza una estructura repetitiva para identificar números pares e impares y calcular sus respectivas sumas.

### 5. Pirámide de Asteriscos
Este programa utiliza estructuras repetitivas para generar una pirámide formada por asteriscos de acuerdo con la cantidad de filas indicada por el usuario.
